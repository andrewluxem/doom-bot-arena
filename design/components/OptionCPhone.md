# Option C · Phone

The editorial grid keeps two columns on a phone, with each tile's label block collapsing to one line (numeral, name, state, frags) above its 4:3 feed.

- Standings collapse to a single ruled line naming the leader and the top three; tap `Standings +` for the full column.
- Because the label blocks keep their typographic weight, the grid shows about 3½ rows and scrolls under a pinned dock (timeline + bottom-right map). This is C's density cost; A fits all eight.
