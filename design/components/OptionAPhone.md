# Option A · Phone

The 4×2 wall rotates into a tight 2×4 grid of `tile--xs` feeds so all eight stay on screen at once on a 390×844 phone.

- Standings collapse to a drawer showing the top three; tap to open the full table (the open drawer is shown in `OptionBPhone`).
- The dock is pinned: a single-lane frag timeline with overview, and a compact map in the bottom-right corner (`TAP ⤢` expands it full-screen). The grid ends above the dock, so the map never covers a tile.
- At this size the map drops ID labels and keeps dots and cones; IDs return when expanded.
- Tap a tile to focus it: the stage takes the top of the screen at full width and the other seven become a horizontal strip.
